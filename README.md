# timtimlive/.github

Default community health files for every repository under [github.com/timtimlive](https://github.com/timtimlive), plus the profile page.

| File | Used for |
|---|---|
| [`profile/README.md`](profile/README.md) | The page people see on github.com/timtimlive |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to contribute |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability privately |
| [`SUPPORT.md`](SUPPORT.md) | Where to get help |
| [`GOVERNANCE.md`](GOVERNANCE.md) | Who decides and how |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE) | Bug, feature, integration request and documentation forms; blank issues off; security goes private |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | The pull request checklist |

A repository that has its own copy of one of these files uses its own copy instead.

`profile/README.md` is shown on the organization page, https://github.com/timtimlive.
